Comment ça se passe

  1. 01

    Vous choisissez

    Le format qui correspond à votre situation. En cas de doute, l’analyse aide à y voir clair.

  2. 02

    Vous réservez

    Le bouton de la formule ouvre l’agenda en ligne de Shirley pour fixer le rendez-vous.

  3. 03

    Vous préparez

    Votre CV, votre profil LinkedIn et, si vous l’avez faite, votre Analyse Le Bon Angle.

  4. 04

    On travaille

    Selon le format : arbitrage, réécriture, stratégie, préparation. Avec des livrables écrits.

Engagements

Ce que l’accompagnement n’est pas

  • Une garantie de recrutement : personne ne peut la donner honnêtement.
  • Une recherche d’emploi faite à votre place.
  • Un rôle prédéfini plaqué sur votre parcours.
  • Un diagnostic médical ou un suivi thérapeutique.

Une approche compatible avec les profils neuroatypiques

Charge cognitive, besoin de clarté, communication, entretiens, environnement de travail : ces dimensions peuvent être prises en compte si vous le souhaitez. C’est une possibilité, pas une condition. Vous partagez ce que vous jugez utile, rien de plus.
